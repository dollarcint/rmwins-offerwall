Use Cases

The RM Wins Offers API supports fetching real-time offers, asynchronously caching inventory, and retrieving offers for a placement.

Request Query Params

The Offers API accepts a GET request with these query params:

keyREQUIREDData type: string

Your account's API Key.

pubidREQUIREDData type: integer

Your sequential RM Wins publisher ID. Example: {{ portal_publisher.publisher_code }}

app_idREQUIREDData type: string

The unique identifier for this placement.

platformOPTIONALData type: string

Valid values: iPhone, Android, All. Default: All.

countryOPTIONALData type: string

User country ISO code or All. Default: All.

typeOPTIONALData type: string

Use live_surveys to fetch live surveys.

payoutTypeOPTIONALData type: string

Valid values: percentage, flat.

Route Response Data

200 means success; 400 contains a message describing the invalid request.

WebView Integration Checklist

  • JavaScript Enabled: Set javaScriptEnabled = true.
  • User Identifier: Replace {SID} with the unique user ID.
